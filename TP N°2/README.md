# TP2 - Aprendizaje Automático

Trabajo práctico de la materia **Aprendizaje Automático**, basado en la predicción de aprobación o rechazo de solicitudes de préstamos.

## Objetivo

Implementar y evaluar algoritmos de clasificación utilizando un conjunto de datos de solicitudes de crédito, considerando personas de entre **40 y 45 años**.

## Contenidos

* Preparación y división del conjunto de datos.
* Implementación del algoritmo **ID3** utilizando:

  * Entropía de Shannon.
  * Ganancia de información.
* Construcción del árbol de decisión.
* Clasificación de datos de prueba.
* Matriz de confusión.
* Accuracy y F1-Score.
* Implementación y evaluación de **Random Forest**.

## Tecnologías

* Python
* Pandas
* Math
* Random

## Dataset

`loan_data.csv`

El conjunto de datos contiene información sobre personas que solicitaron créditos bancarios, incluyendo características personales, económicas y del préstamo.

## Resultado

Se comparan los modelos implementados mediante métricas de clasificación para analizar su desempeño en la predicción de solicitudes **OTORGADAS** y **RECHAZADAS**.
